# Airline Seating Manager (CS3)

A small airline needs a program for managing the seating configuration of one of its aircraft. Different sections of the aircraft may have different numbers of seats in each row. For example, first-class rows may contain fewer seats than economy rows. My program allows airline employees to view the aircraft's seating information, locate a passenger or seat, update reservation information, add a seat when the aircraft configuration changes, and remove a seat from a row. Your program should also be able to find available seats that meet a passenger's requested seating class.
